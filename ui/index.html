02  /  柔焦参数

星点识别与光晕

按星空区域内 SEP 圆孔径通量相对最亮点源的比例筛选，默认 6.3%（约相当于比最亮点暗 3 等），达标点源全部处理，不设数量上限。该值是画面内相对通量，不是星表绝对星等；绝对星等需要天文解算后匹配 Gaia 星表。强度默认 10、最高 30，控制扩散宽度；光晕不透明度默认 30%，数值越高光晕越明显。亮度同时决定光晕半径与强度。星云、星系等弥散结构不作为星点柔化；球状星团中的紧致成员星可在拥挤星场中继续识别。场景预览会估计地平线并遮罩前景区域。星色取自原图 RGB 孔径测光。
